### 已补齐的真实行为

- 核销撤销/更正与凭证一致；旧草稿失效、已入账记录由有留痕的修订替代，避免重复计账。
- 手工凭证入账核验有效来源、原件归属和内容哈希；调整、暂估、结转可使用相应依据。库存损耗关联实际物料与库存流水，普通单据号不再被误当作来源 ID。
- 首次及最终确认使用显示中的冻结快照，绑定版本与底稿时间；普通确认、重大事项签名和工资/社保独立确认保留。
- 月度档案真正包含原始附件，原件缺失或损坏时准确标注不完整；按归档时模块配置判断要求。
- 凭证附件及月度包增加 PDF/图片合并预览与来源页码清单，原件仍保留；不支持/损坏文件明确列出。
- 附件导出记录不再使财务源指纹变化；真实分录和证据变化仍使旧冻结失效。
- 历史归档在创建时独立复制，后续活动记录更新不会改写历史快照；旧凭证仅有日期时也纳入本期检查与归档。
- 进入下一期时将本期利润/亏损正确转入权益，保留可追溯的结转来源。
- 工作台备份 ZIP 包含业务数据与可用原件，支持合并/替换恢复、同名/同 ID 隔离、损坏拒绝和失败保留旧数据；旧 JSON 导入保留。
