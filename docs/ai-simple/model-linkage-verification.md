## 这份集成源码要证明什么

| 场景 | 可观察断言 |
| --- | --- |
| 获取模型、选择后请求 | 模型列表客户端经过真实列表代理；会话选择传到真实对话代理的上游 model/thinking/reasoning_effort |
| 模型身份 | 官方响应 model 与 requestedModel 分开；回调、保存的消息和重载结果保留身份；缺少响应 model 时保留 null |
| 历史与工具续轮 | 旧对话仍作参考；工具实际读取本地报表；本轮 reasoning_content 继续回传，却不进入公开回调、结果或持久化 |
| 取消、超时、无效 Key | 上游请求收到 abort；无自动重试或后续工具写入；此前原件和待确认导入保留 |
| 双入口共用账本 | 简版确认手续费产生凭证草稿；真实模式控制器切到完整入口，调用共享财务服务入账，再返回简版；原简版服务、两种报表和下一轮工具均读到25元费用 |
| 标签页会话 | 原 File 引用、草稿与 Key 保留；Key 不进入 UI snapshot、history state 或账本；新建独立会话没有 Key 或草稿 |
| 事项定位 | 用实际导入/确认生成的 ID，解析原件、流水、凭证目标；错误公司、账期及不存在对象被拒绝 |
| 最小边界 | 公司/账期改变后的旧请求不能导入；草稿按目标隔离；合成归档账期能读原件/报表、不能确认或工具写入 |

模式测试调用生产代码的 history 控制器，浏览器 history 本身由内存适配器提供。**它不能证明 React 挂载、页面按钮、滚动位置或弹窗返回已经正常**。合成归档标记仅用于只读边界，不表示真实月结归档流程被验收。报表金额来自共享财务核心；模型最终回复文字是夹具文本，不能算真实模型理解能力。

## 最短浏览器清单（由总控执行）

使用独立验收浏览器上下文和新建合成工作台，账期设为 `2026-09`，不要在用户现有账本导入。银行资料可直接用 `tests/fixtures/ai-model-linkage/合成银行流水.csv`，导入列选择“发生额”，两笔应为 -25、-15；“余额”列975、960用于辨认错误映射。

1. 先确认三个直接入口：无参数地址默认进入 AI，`?mode=ai` 仍进入 AI，`?mode=full` 明确进入完整工作台；AI 首页保留蓝色渐变和简洁输入框。填一段未发送文字并添加上述文件，先保存模型选择。通过各页顶栏和资源弹窗的直接切换入口，在同一标签页进入完整工作台，再返回，确认公司、账期、文字、附件、模型选择保留；完整入口 URL 为 `?mode=full`，URL 与界面模式一致，浏览器前进/后退可用。补一个实际保护场景：完整工作台有未保存编辑时按 Back/Forward，拒绝离开后继续编辑，再正常切换并返回；URL 与页面一致、不重复发送，资源页位置及草稿仍保留。完整工作台白色/浅蓝灰及蓝色控件另由总控视觉验收。
2. Key 留存只用明显标记为合成的测试值，**不点击发送或模型刷新，除非验收浏览器已拦截对应 API**。切换后仍显示已配置；清除后显示未配置。页面刷新会丢失 Key；有草稿时遵从页面未保存提示。检查浏览器 Key 持久化边界由总控提前说明范围。
3. 模型交互若使用已有请求拦截工具：仅拦截 `/api/deepseek-models`、`/api/finance-assistant`，先确认请求不会发给 DeepSeek，再使用夹具模型结果。选非默认模型，发送一次，核对实际请求字段与回复标签；另一次省略响应 model，应显示未返回身份。无拦截能力时跳过这步，把模型协议证据限定为 Node 测试，不请求真实 Key。
4. 通过现有本地流水入口导入合成CSV，确认 -25 元手续费的业务归属并生成草稿。分别打开该原件、流水、凭证，确认显示的就是所点 ID；从事项切至完整工作台再返回时，回到原事项及资源页签。指定原件没有导入批次时，应给出提示，不能变成全部流水。
5. 在完整工作台复核并入账25元凭证后返回简版：费用25元、利润 -25元、现金净变动 -25元；另一笔15元未入账，不计入报表。打开现金流量表或资产负债表，点来源凭证，再返回，必须保留原报表页签。若用受控模型回放，再问一次报表并核对工具结果25元，区分工具事实与夹具回复。
6. 切到另一合成公司或下一账期，确认原事项不能误开、新输入与原草稿分开；返回原目标后草稿仍在。归档只读边界优先使用独立测试夹具，不为本轮在真实用户账本执行归档。

受控响应案例、取消/超时/无效 Key 与上述本地操作可以分别验收；不要把接口回放称为“DeepSeek 已连通”。
