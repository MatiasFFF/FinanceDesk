| 同文件重传不能恢复缺失原件 | `uploadFiles` 找到同账期/hash/category的旧索引后直接 `readOriginal`；vault字节丢失或损坏时重复上传仍失败，没有恢复支路 | 后端只在内容匹配及原件归属安全时恢复原字节，保留 documentId 和既有引用。独立测试先移除内存原件并确认旧导入被阻止，再重载、重传同文件、确认原 pending 建议；验证导入不重复，后续入账和实际 XLSX 仍指向原 documentId |

源文件为 `src/application/aiFinanceService.js`、`src/application/aiFinanceTools.js`、`src/application/deepseekClient.js`、`src/store/financeDeskStore.js`。第一次集成验证另外暴露：24,000字中文结果超过客户端64,000字节上限后再次截断，原 nextOffset 会跳过正文。已改为按实际传输字节裁出连续正文，并同步续读位置，完整正文拼接断言保持通过。各修复由后端任务实施；后端另负责损坏字节、异公司 blob 所有权及取消边界的定点测试。

## 独立集成测试

新增 `tests/ai-completeness-integration.test.mjs`，复用现有 `tests/helpers/aiSimpleJourneyFixture.mjs`，不新增验证框架或依赖。总控说明目的后执行：

```sh
node --test tests/ai-completeness-integration.test.mjs
```

三个案例覆盖：

1. **多文件确认失败恢复与导出实物。** 第一批为37.25元及12.75元费用，第二批91.20元仍待确认；第一批建议状态保存打断并重载恢复后，只入账37.25元。用 `generateAiReportExcel` 生成字节，再通过 `XLSX.read` 解码，核对草稿阶段费用0、待入账凭证记录，以及入账后费用37.25、利润/现金净变动 -37.25、正确凭证和原件引用；另一批未确认资料不进入报表来源。
2. **长正文续读与人工确认。** 原件和识别结果通过现有本地保存函数写入内存 vault；正文合计位于首次读取之外。真实客户端、代理与工具链执行两次 read_document 和一次字段建议；合并读取文字应与所存正文一致。人工确认前保留原100元，确认后为1876.54元，同时保留原文件字节、hash、unverified状态和0张凭证。
3. **缺失原件恢复后完成原建议。** 恢复前原建议不能导入；同文件重传后保持一份资料、一份原件和原建议，确认产生两笔唯一流水。用真实凭证附件清单生成原件导航目标，读取目标原件字节并核对返回凭证 ID；入账68.40元后从实际 XLSX 读回费用及现金净变动，原件引用仍为恢复前的 ID。页面按钮及显示仍需浏览器验证。

所有业务输入、文件与请求 Key 都是合成夹具，仓库和文件库仅存在内存。只替换外部 DeepSeek 响应；客户端、代理校验、工具、确认、入账、报表计算和 XLSX 序列化使用实际代码。长正文案例使用**已保存识别结果夹具**，不证明 PDF 解码或 OCR 引擎运行；受控模型的提取文字也不证明真实模型理解。Excel 字节生成及解码不等于浏览器下载已经落盘。

## 总控最短浏览器复验项

使用合成工作台，真实 DeepSeek 继续暂缓。以下来自本轮对应实施任务的源码确认或修复交接，均待总控实际点击/看图，不能用 Node helper 通过代替：

- 设置或新建工作台有未保存输入时，X、Escape、背景及模式/历史切换应遵从离开保护；首页明确发送后完成创建或 Key 配置，只续发原请求一次，取消、普通设置或切换目标不发。
- 建议确认弹窗添加账户或确认最后一条建议时，其余账户输入、说明及编辑草稿不被静默丢弃。
- 凭证“来源、附件与历史”原本仅有名称文字，事项任务补原件跳转和返回当前凭证/流水；手动展开凭证后跨模式仍指向该凭证。实际点击、原件显示及返回需浏览器证实。
- 1024×500或844×390的低高度首页：多份长文件名附件、多行输入和格式提示下，首份附件移除及发送可通过正常滚动访问，不藏在顶栏后。
- 1024×600及390×500的对话页：同时有待确认、长进度、多条错误和草稿附件时，消息区仍至少128px高，底部可独立滚到发送/停止；390×844建议确认弹窗中，仅宽预览表格横向滚动，确认/取消可纵向滚达。

报表导出已有卸载和数据版本变化保护，本轮没有重复修改。Accounting 早期“漏传已有 onNavigate”猜测经读取撤回：实际缺口是凭证组件本身只有附件文字，后续由事项任务最小新增导航能力。
