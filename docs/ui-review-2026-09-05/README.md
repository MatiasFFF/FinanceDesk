## 1. 月结总览：待办应早于大面积统计

空工作台首屏有四张大面积零值卡，实际待办位于更下方；下一步提示已出现“冻结报表”，需要核对是否正确遵循尚未完成的资料和银行步骤。空状态应显示真实待办，并用紧凑统计辅助判断。

负责人：报表与跨期优化。此次只修正与当前阶段数据直接相关的提示，不扩大业务流程。

## 3. 批量核销：交易列表应成为默认工作区

会员业务、往来账单和完整手工凭证编辑器排在银行交易列表前面。首次进入需要滚动多屏才能找交易。空白手工凭证还在用户开始填写前显示错误。

改为银行交易默认可见；往来、会员来源和手工凭证使用清楚的页内入口，按需展开。手工凭证保留真实创建、证据和入账流程，避免将功能隐藏成无法使用的装饰入口。

负责人：报表与跨期优化调整 `App.jsx` 的父级布局；核销与凭证优化调整其组件内部。

## 4. 单笔复核：侧栏应集中处理当前交易

选中一笔交易后，右侧约 380 像素宽；左侧筛选与搜索拥挤。侧栏又嵌入完整会计工作台与账簿，主操作沉到下面，并露出 S5–S8、sourceIds 等实现用语。

应突出本笔金额、业务判断、资料缺件与下一动作；关联记录可展开追溯，但全局账簿不应重复铺在窄栏里。筛选栏应能换行，避免压缩或遮挡。保留缺件、复核与权限的真实约束。

负责人：核销与凭证优化处理会计组件；报表与跨期优化处理侧栏与交易列表布局。

![修改前的单笔交易复核](/Users/matias/Project/FinanceDesk/docs/ui-review-2026-09-05/04-transaction-review.png)

## 5. 报表中心：减少重复状态，让数字与处理入口提前

版本工具栏、警告条、四张大卡占据首屏；具体报表和勾稽入口在下方。禁用的导出按钮改成了“请选择当前冻结版本”，看不出按钮本来的用途。

版本选择、冻结和导出使用紧凑工具栏。固定“导出 Excel”等动作名称，在旁边解释禁用原因。保留一处清楚的差额摘要及处理入口，减少重复警告和多层卡片。

负责人：报表与跨期优化。

![修改前的报表中心](/Users/matias/Project/FinanceDesk/docs/ui-review-2026-09-05/05-reports.png)

## 6. 确认与申报：先回答当前能做什么

大幅未连接提示、十多张金额卡和底稿参数排在首次确认前面；后面的导出区域再重复整组前置条件。应在首屏先显示当前阶段、阻塞项和下一步，将税额与工资社保按主题分组，参数按需展开。

保留两次确认、重大事项签字、本地估算与“未提交税务局”的必要说明。不得为了简洁隐藏真实风险或放宽条件。

负责人：报表与跨期优化。

![修改前的确认与申报](/Users/matias/Project/FinanceDesk/docs/ui-review-2026-09-05/06-confirmation.png)

## 7. 归档和资料库：文件应容易找到，状态应准确

归档页面大卡占据大部分首屏；演示资料出现“已归档”和“原文件不可用”并列，需要区分记录状态与原件状态。资料库更长：上传后依次铺开合同计划、发票、工资、差异、缺件、凭证包、月度包，文件搜索与列表排在最后。

资料库默认显示文件列表、搜索和上传入口；合同/发票、工资社保、缺件、导出包按任务分组切换。月度包清楚显示“完整”或“草稿”、缺少什么、下一步在哪里，不用哈希和内部 ID 充当主文案。保留原件校验和追溯信息的查看入口。

负责人：资料与档案优化处理资料库；报表与跨期优化处理 `App.jsx` 中的归档页面及准确状态文案。

## 实施边界与验收

三个实现任务继续使用当前项目和 `main`，不创建分支或工作树，不使用 Computer Use，不启动服务、不测试、不提交。它们可在提前说明后静态核对各自文件。总控统一处理运行验证、视觉回看、提交和共享文件冲突。

1. **资料与档案优化**：原 F4/F6 范围，加 `FoundationRecordsPanel.jsx`、`foundation-ui.css`、`document-intake-panel.css`。不改 `App.jsx` 或 `styles.css`。
2. **核销与凭证优化**：原 F2/F7 范围，加 `accounting-workbench.css`、`manual-voucher-panel.css`。不改 `App.jsx` 或 `styles.css`。
3. **报表与跨期优化**：原 F1/F3/F5 范围，加 `src/styles.css`；独占 `App.jsx` 及全局样式，负责父级布局和跨组件协调。

本轮可见验收点：银行交易默认出现；资料库默认能找文件；打开编辑器后才出现相关表单；报表和确认页有明确下一步；按钮用途稳定；没有重复边框、横向遮挡或暴露内部实现的主文案。功能约束、未保存输入和已归档数据不得因切换面板而被静默丢弃。
